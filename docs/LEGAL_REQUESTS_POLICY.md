# ValueSkins policy for requests from public authorities

1. Every request from a public authority for user data is reviewed for legality before any data is shared, with legal advice where needed.
2. If a request is unlawful, overly broad or improperly served, ValueSkins challenges or declines it.
3. ValueSkins discloses only the minimum data needed to answer a valid request.
4. ValueSkins records every request: who asked, when, what was asked, what was disclosed, and the legal reasoning.

Owner: the founders of Valueskins Private Limited. Reviewed: November 2026.
